# State Health Data Portals

Catalog of official state health data portals, one entry per state. Every source this repo
collects today is federal; this doc is for finding state-level data that CDC either doesn't
publish nationally or publishes only in aggregate.

For the subset that has been probed against a live endpoint, with dataset IDs and column
names confirmed, see [State & Local Sources](local.md). That page goes deep on a dozen
portals; this one goes wide across all 51 jurisdictions.

Every URL here was found through a live search and points at a state agency or its data
platform. Where a state runs more than one system, the primary query/download portal is
listed first.

## Common Platforms

Several states run the same underlying software, which is worth knowing before writing a
scraper. If you can parse one, you can usually parse its siblings.

- **IBIS-PH** (Indicator-Based Information System for Public Health): open-source query
  system originally built by the Utah Department of Health. Adopting states rename it
  (NJSHAD in New Jersey, NM-IBIS in New Mexico). Layout is consistent: indicator reports,
  community profiles, and dataset queries that emit custom tables, charts, and maps.
- **Socrata** (now Tyler Data & Insights): powers many statewide open data portals. Every
  dataset gets a SODA API endpoint, so `https://<host>/resource/<id>.csv` works the same
  way `data.cdc.gov` does in this project. See [CDC Open Data](cdc-open.md) for the query
  syntax, and `src/cdc_open/` for a client that already speaks it.
- **ArcGIS Hub**: used for map-first and dashboard-first publishing. Underlying data is
  usually reachable as GeoJSON or CSV through the feature service, though it is rarely
  advertised.
- **Environmental Public Health Tracking (EPHT)**: CDC-funded state tracking networks with
  a shared data model, covering environmental hazards next to health outcomes.

## What This Means For Adding State Data

If the goal is collecting state data alongside the CDC series this repo already archives,
the states sort into four tiers by how much work ingestion would take.

Genuinely automatable today, because they expose a documented API over stable dataset IDs:
New York (`health.data.ny.gov`, Socrata/SODA), California (`data.chhs.ca.gov`, CKAN), and
the statewide Socrata portals in Connecticut, Maryland, Colorado, Oregon, and New Jersey.
These behave like `data.cdc.gov` and would need almost no new fetching code.

Query systems with good data but no API: Wisconsin WISH, Georgia OASIS, Missouri MICA,
Oklahoma OK2SHARE, Utah and New Mexico IBIS-PH, Florida CHARTS, Pennsylvania EDDIE, and
North Carolina's query system. These generate tables on demand from form posts. Scraping
is possible but brittle, and the IBIS-PH states are worth attacking together since they
share a URL structure.

Report-only states, where the data exists but arrives as PDF: South Dakota, Idaho,
Montana, Arkansas, Alaska, and West Virginia. Extracting trend series from these means
parsing annual reports, and the effort rarely beats just using the CDC national files.

Blocked or restricted: Illinois IQuery requires an Illinois.gov account, parts of Ohio's
warehouse sit behind an OHID login, and Montana routes most non-vital data through a
formal request process. Wyoming publishes the least of any state here.

Two caveats that apply everywhere. Small-cell suppression differs by state, which changes
what county and zip queries return: Iowa suppresses counts of five or fewer, and Missouri
runs a multi-level suppression scheme that varies by user access. And state numbers will
not tie out against the CDC series this repo collects, because the vintage, residency
rules, and age-adjustment standards differ.

## Validating NY and CA Against CDC

Measured August 2026 by pulling weekly respiratory admissions from each state portal and
comparing them against the same week in CDC NHSN (`data.cdc.gov/resource/ua7e-t2fy`),
which carries a per-jurisdiction breakdown plus a `USA` row. The result changes which of
the two states is worth adding.

**California republishes CDC.** Its Respiratory Virus Dashboard is not an independent
count. For flu admissions, 89 of 90 comparable weeks are numerically identical, the sole
exception being the week ending 2025-11-29 (CA 218, CDC 217). For COVID admissions, 88 of
98 weeks are identical. Collecting California as a separate series would duplicate data
this repo already archives under a different name.

The COVID divergence is confined to nine weeks, from 2024-09-07 through 2024-10-26, where
California ran higher than CDC by between 25% and 213%. Exact agreement begins the week
ending 2024-11-02 and holds through the present. That boundary lines up with the end of
the voluntary-reporting era that health-charts' `DATA_SOURCES.md` flags for RSV, which suggests
California kept fuller counts while NHSN reporting was optional and then aligned once it
was not. Treat that as the likely explanation rather than a confirmed one.

**New York is genuinely independent, and consistently higher.** Summing the facility-level
table `vgyq-b7tb` to statewide weekly COVID admissions gives numbers above CDC's New York
figure in every one of the 43 overlapping weeks (2025-10-04 through 2026-07-25), with a
median ratio of 1.23 and a range of 1.09 to 2.29. Flu tells the same story: summing the
county-by-age table `iye6-rifr` across 66 weeks runs above CDC, by 5% to 17% during peak
weeks. The headline 34% mean absolute difference for flu is misleading, since off-season
weeks with tiny counts dominate the percentage; peak-season agreement is much tighter.

The direction is stable enough that New York looks like a broader denominator (state
reporting mandates covering more facilities than NHSN captures) rather than noise, but
neither portal documents the reconciliation, so the cause is unconfirmed.

**Scale.** Across the 2024-25 season New York accounted for 6.6% of national COVID
admissions and California 9.5%; in 2025-26, 6.3% and 8.8%. California's share sits well
below its population share, roughly 39.4 million of about 340 million, or 11.6%, per the
Census Bureau's Vintage 2024 estimates.

Practical upshot: New York adds a real second view and California does not. Any state
series should be labeled as state-sourced rather than blended into a national line, since
the two sources disagree by a fifth or more on the same weeks.
